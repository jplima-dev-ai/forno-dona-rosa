Artigos

Crie e atualize conteúdos editoriais sem editar HTML. O layout, breadcrumbs, SEO e sitemap continuam sendo gerados pelo projeto.

Ex.: historia-do-forno. O arquivo gerado continua com nomes técnicos em inglês quando aplicável ao projeto; o slug público pode refletir a copy.

Backup e aplicação

O bundle exportado contém apenas dados de configuração e catálogo. Ele não contém senhas, tokens ou dados de clientes.

Para aplicar no repositório: coloque o arquivo exportado na pasta do projeto e execute python tools/apply-admin-bundle.py arquivo.json. O script cria backup, valida os dados e atualiza os arquivos canônicos.
