# Fundamentos

O design system combina direção editorial gastronômica com clareza de commerce. A hierarquia prioriza decisão e compra antes de elementos decorativos.

## Princípios

- uma ação dominante por contexto;
- conteúdo antes de chrome;
- mobile como composição própria, não desktop encolhido;
- tokens de marca separados do comportamento do core;
- acessibilidade preservada em qualquer skin;
- motion e ornamentação apenas quando ajudam compreensão.
