# 4.0.8 — Performance & Resilience

## Tese
Experiência premium precisa continuar compreensível quando rede, cache, storage ou mídia falham.

## Entregas
1. Performance budgets declarativos.
2. Resilience runtime para storage, rede, mídia e Sacola obsoleta.
3. Handshake de versão com Service Worker.
4. Fallback visual e semântico para imagem quebrada.
5. Quality gate e testes adversariais.

## Evidência
Budgets são metas. Não devem ser apresentados como Core Web Vitals medidos até execução real em navegador/ambiente publicado.
