# Release 3.4.9 — Business Configuration Studio

A versão 3.4.9 introduz a primeira superfície administrativa do projeto. O objetivo não é criar um CMS genérico, mas reduzir drasticamente o conhecimento técnico necessário para configurar uma pizzaria.

## Entregas principais

- rota `/admin/` com `noindex`;
- marca e contatos editáveis;
- operação de entrega/retirada/pagamento/agendamento;
- horários semanais;
- editor de produtos e preços;
- disponibilidade e merchandising;
- copy principal;
- editor de molhos;
- rascunho local;
- importação e exportação de bundle;
- aplicação segura com backup e rollback;
- validação estrutural e comportamental dedicada.

## Limite arquitetural

A versão 3.4.9 não declara autenticação, banco de dados ou publicação remota. GitHub Pages continua sendo o destino static-first. O painel foi desenhado para receber uma camada backend autenticada posteriormente.
