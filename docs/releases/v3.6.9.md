# v3.6.9 — Security & Reliability Hardening

A linha 3.6 foi dedicada a correção de bugs e endurecimento das fronteiras de segurança do storefront e do Admin Studio.

## Principais mudanças

- Admin Studio e `/dev/` excluídos do cache/interceptação do Service Worker.
- Import administrativo limitado a JSON de até 2 MB.
- Recuperação segura de rascunho local corrompido e tratamento de falha de quota.
- URL do crédito aceita somente HTTPS.
- Aplicador CLI limita tamanho do bundle, catálogo, textos e preços e mantém rollback atômico.
- Crédito padrão atualizado para **Desenvolvido por KJ Productions**.
- Novos gates `security-hardening-check.py` e `security-behavior-check.js`.

## Limites

A automação desta release não substitui pentest externo, teste manual com tecnologias assistivas nem revisão server-side, pois a versão estática não possui backend/autenticação.
