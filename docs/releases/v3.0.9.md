# v3.0.9 — Production Website

A linha 3.0 transforma a referência Dona Rosa de uma landing page avançada em um site comercial multipágina, mantendo o núcleo estático, acessível, mobile-first e publicável no GitHub Pages.

## Arquitetura pública

- `/menu/` — cardápio completo;
- `/order/` — pedido dedicado;
- `/about/` — história;
- `/experience/` — processo e posicionamento;
- `/location/` — endereço, horários e retirada;
- `/help/` — FAQ operacional;
- `/privacy/` — privacidade;
- `/products/<id>/` — uma URL para cada produto do catálogo.

## Correção importante

Ao restaurar uma sessão cujo recebimento era **Retirada na pizzaria**, o checkout podia recuperar o rádio correto sem reaplicar o estado visual dos campos de entrega. A 3.0.5 reaplica o contrato após a restauração, desabilita controles de entrega ocultos e invalida lookup de CEP pendente.

## Extras do pedido

O checkout aceita molhos opcionais configurados pela marca. Na referência Dona Rosa: Maionese, Ketchup, Mostarda, Molho de alho e Molho picante.

## Evidência

Automação e checks executáveis não substituem NVDA, JAWS, Narrator, TalkBack, VoiceOver ou teste físico. Esses itens continuam não verificados até execução real.
