# v2.6.9 — Template Factory & Production Readiness

## Summary
The 2.6.x line converts the v2.5 white-label foundation into a repeatable client-creation and quality workflow. It adds formal configuration contracts, client generation, presets, capability-aware component behavior, production diagnostics, documentation drift checks and a reproducible CI-friendly quality command.

## Highlights
- Machine-readable brand/content/catalog schemas.
- `tools/create-brand.py` and `tools/apply-brand.py`.
- Pizzeria and coffee-shop capability presets.
- `tools/project-doctor.py` with cross-layer invariants.
- `tools/template-factory-check.py` proving a second preset can be generated and validated.
- `tools/docs-check.py` preventing stale technical documentation.
- `npm run quality` and a cross-platform GitHub Actions workflow.
- Container-query and long-content resilience refinements.

## Compatibility
The active Forno Dona Rosa reference implementation keeps the existing `forno` storage namespace and customer-facing Portuguese experience.

## Evidence boundary
The automated suite validates static contracts and local behavior. It does not claim real NVDA, TalkBack, VoiceOver, Axe or Playwright execution unless those tools are separately run and recorded.
