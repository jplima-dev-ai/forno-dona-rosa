# v3.3.9 — Real Storefront Experience

A linha 3.3 transforma o site multipágina em uma vitrine operacional mais viva: status aberto/fechado, merchandising editorial honesto, recuperação de produtos indisponíveis, páginas de produto 2.0, mídia responsiva AVIF/WebP, infraestrutura de reviews sem conteúdo fictício e hardening mobile.

- `tools/storefront-experience-check.py`
- `tools/business-status-behavior-check.js`
- todos os gates legados permanecem no `npm run quality`.
