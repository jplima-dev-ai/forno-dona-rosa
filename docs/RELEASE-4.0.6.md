# 4.0.6 — Admin Studio 4

## Tese
O Admin deixa de ser apenas um editor local e passa a responder: “este rascunho está saudável para seguir ao quality gate?”.

## Entregas
1. Content Health no próprio Admin Studio.
2. Readiness com bloqueadores, revisões e observações.
3. Auditoria de catálogo, mídia 4.x, conteúdo, artigos/SEO e prova social autorizada.
4. Navegação direta do alerta para a área que precisa de correção.
5. Quality gate da release e versão do Admin alinhada ao storefront.

## Limite deliberado
Continua sem autenticação server-side e sem publicação automática. A saída permanece bundle local validado + quality gate + Git/GitHub Pages.
